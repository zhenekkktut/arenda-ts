# Аренда ТС

Приложение для учёта интенсивности эксплуатации автомобиля, расчёта аренды, истории счетов и оплат, расходов и выгрузки отчёта в Excel.

## Открыть и установить

- [Открыть защищённое веб-приложение](https://arenda-ts.yudzhinnn.chatgpt.site)
- [Скачать актуальный APK для Android](https://github.com/zhenekkktut/arenda-ts/releases/download/android-latest/arenda-ts.apk)

На Android разрешите установку из браузера, откройте скачанный `arenda-ts.apk` и нажмите «Установить». При первом запуске потребуется войти в тот же аккаунт, которому открыт доступ к веб-приложению.

В Chrome приложение также можно установить без APK: откройте веб-приложение и нажмите «Установить» либо выберите «Добавить на главный экран» в меню браузера.

## Что хранится где

- Рабочие записи, счета, оплаты и расходы хранятся в защищённой серверной базе.
- GitHub и APK не содержат рабочие данные, реквизиты и пароли.
- Android-приложение открывает ту же актуальную версию и ту же базу, что и веб-приложение.

## Автоматическая сборка

GitHub Actions собирает подписанный APK при каждом изменении ветки `main`, сохраняет его как артефакт сборки и обновляет постоянную ссылку в разделе Releases.

Каталог `android/` содержит Android Trusted Web Activity с безопасным переходом в Chrome. Так сохраняется вход в закрытый сайт и корректно работают загрузка исходных таблиц и скачивание Excel. Из-за закрытого доступа APK при первом входе может показать компактную строку браузера; установленная из Chrome PWA открывается без неё.

> `android/debug.keystore` используется только для прямой внутренней установки и стабильных обновлений. Для публикации в Google Play нужно заменить его приватным ключом из защищённых GitHub Secrets.
